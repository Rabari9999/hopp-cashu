# Tasks

Concrete pieces of work that are decided but not yet done — one file each,
with why, what to build and when it counts as done. Decisions themselves
live in `docs/adr/`; a task points to the ADR it implements. Delete the file
(or set its status to `done`) in the commit that finishes it.
